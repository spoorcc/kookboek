# Kookboek — GitHub Pages

A searchable recipe index with an in-browser PDF viewer, auto-deployed on every push to `main`.

## One-time setup

### 1. Enable GitHub Pages

Go to **Settings → Pages** in the repository and set:

| Field | Value |
|---|---|
| Source | Deploy from a branch |
| Branch | `gh-pages` |
| Folder | `/ (root)` |

Save. The site will be live at `https://<owner>.github.io/<repo>/` after the first successful workflow run.

### 2. Merge this branch to `main`

The workflow (`.github/workflows/gh-pages.yml`) only runs on pushes to `main`. Once merged, it will:

1. Build the PDF with XeLaTeX
2. Extract recipe titles, chapters, and page ranges from the PDF bookmarks (`scripts/extract_index.py`)
3. Downsample the print PDF into a low-resolution web copy (`scripts/make_web_pdf.py`)
4. Copy `KookboekFamilieSpoor.pdf`, `KookboekFamilieSpoor-web.pdf`, and the generated `recipes.json` into `docs/`
5. Push the `docs/` folder to the `gh-pages` branch

## How the site works

| File | Role |
|---|---|
| `docs/index.html` | Single-page app — committed to the repo |
| `docs/recipes.json` | Recipe index — generated by CI, not committed |
| `docs/version.json` | Build info (`{"ref": "<tag-or-short-sha>", "date": "<build date>"}`) — generated by CI, not committed |
| `docs/KookboekFamilieSpoor.pdf` | Full print-resolution PDF — generated by CI, not committed. Only linked from the "↓ Volledig boek" button, never fetched into the page |
| `docs/KookboekFamilieSpoor-web.pdf` | Downsampled copy of the same PDF (`scripts/make_web_pdf.py`) — generated by CI, not committed. What the viewer and "↓ Recept" actually load, for a much faster page load |

On load, `index.html` fetches `recipes.json` to build the sidebar, then fetches the low-res web PDF once and caches it in memory (shared between the PDF.js viewer and pdf-lib for the per-recipe download).

## Features

- **Search** — filters the recipe list in real time by title
- **Two-page spread** — renders the recipe's PDF pages side by side on wide screens, single page on mobile
- **↓ Recept** — downloads only the current recipe's pages as a standalone PDF (uses pdf-lib in the browser, no server needed), extracted from the low-res web PDF. Each page gets a tiny light-gray "versie *ref* · *datum*" stamp in the bottom-right corner, using `version.json`'s git ref/build date, so a printed-out recipe can be traced back to the book build it came from.
- **↓ Volledig boek** — downloads the complete cookbook at full print resolution (`KookboekFamilieSpoor.pdf`), independent of whatever the viewer has loaded
- **Shareable links** — opening a recipe updates the URL to `?recept=<slug>` (e.g. `?recept=hollandse-appeltaart`); sharing that link opens the same recipe directly, and the browser's back/forward buttons move between previously opened recipes

## Local preview

You need a local HTTP server (browsers block `fetch()` from `file://`).

```sh
# From the repo root — after a local LaTeX build that produced KookboekFamilieSpoor.pdf:
python3 scripts/extract_index.py
python3 scripts/make_web_pdf.py KookboekFamilieSpoor.pdf docs/KookboekFamilieSpoor-web.pdf
cp KookboekFamilieSpoor.pdf docs/
cd docs && python3 -m http.server 8080
```

Then open `http://localhost:8080`.
